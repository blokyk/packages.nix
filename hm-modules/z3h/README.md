# `z3h`

A partial "reimplementation" of [zsh4humans](https://github.com/romkatv/zsh4humans)
as a home-manager module. Very much WIP.

This will probably be incomplete since I don't use most of z4h's features, most
notably:
- ssh teleportation
- tmux integration

> [!NOTE]
> This module depends on some of my other modules, which means their options
> will be introduced into your option set. This includes:
> - [zsh-utils](../zsh-utils/README.md)
> - [zsh-powerlevel10k](../zsh-powerlevel10k/README.md)
